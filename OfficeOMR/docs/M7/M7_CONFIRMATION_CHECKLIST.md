### Q1: 标准答案的获取方式

> 系统提供两种方式获取标准答案，都支持吗？

**选项A: 扫描标准答案卡**（推荐快速）
```
1. 打印空白答案纸
2. 老师用笔涂出 100 题正确答案
3. 扫描这张卡
4. 系统自动识别 → answerKey
```
- 优点：快速、自动、重用已有的 OMR 核心
- 缺点：需要打印和扫描

**选项B: 手动输入答案**（备选方案）
```
1. 打开网页界面
2. 逐题选择 A/B/C/D/E
   或粘贴 JSON: ["A","C","B",...]
   或上传 CSV
3. 系统保存 → answerKey
```
- 优点：灵活、不用扫描、可修改
- 缺点：手动输入慢

### Q5: 分数计算标准

> 假设 100 题满分 4.0 分（根据大马教育制度），分数计算公式是什么？

**建议公式**:
```
分数 = (答对题数 / 100) × 4.0

例如:
  87 答对 → 87/100 × 4.0 = 3.48 分
  92 答对 → 92/100 × 4.0 = 3.68 分
  100 答对 → 100/100 × 4.0 = 4.0 分
```
