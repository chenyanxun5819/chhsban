## 🎯 核心问题与改正

### 问题
> 老师在申请新的答案纸的同时，是不是也要先输入这个考题的正确答案？否则在上传学生答案纸时，如何分析？

**答案**: ✅ 完全正确！M7 缺少了这个关键步骤。

### 关键改正（非常重要）

**❌ 错误理解（之前）**:
- 标准答案 24 小时后删除（与学生数据同时）

**✅ 正确理解（Wes 更正）**:
- **标准答案永久保存**（与试卷一起）
- **只有学生数据（答案卡、原图、标注图）24小时删除**

**为什么**:
- 老师改卷可能超过 24 小时
- 如果标准答案被删，老师还得重新上传一遍
- 标准答案应该伴随试卷永久保留，供隔年复用

## 📋 新的 M7 工作流

```
新建考试
  ├─ 选择版型 + 考试信息
  │
  ├─ 【获取标准答案】（必须先做）
  │  ├─ 方案A：扫描标准答案卡
  │  │   └─ 系统自动识别 → 生成 answerKey
  │  │
  │  └─ 方案B：手动输入答案
  │      └─ 逐题选择 A-E 或粘贴 JSON/CSV
  │
  ├─ 【下载答案纸】
  │   └─ PDF（供学生填涂）
  │
  ├─ 【学生作答】
  │   └─ 手涂答案纸
  │
  ├─ 【上传学卷】
  │   └─ 教师上传扫描图
  │
  ├─ 【自动识别 + 对比】
  │   ├─ 识别学号 + 答案
  │   └─ 与标准答案比对
  │       ├─ ✓ 答对
  │       ├─ ✗ 答错
  │       └─ ? 未作答
  │
  └─ 【查看结果 + 导出】
      ├─ 结果表（学号 + 每题 + 对错）
      ├─ 标注图 PDF
      └─ 结果 CSV
```

## 💾 数据保留期对比

| 数据类型 | 保留期 | 说明 |
|---------|--------|------|
| **学生答案卡** | 24小时 | 包含学号、姓名，涉及隐私 |
| **标注图** | 24小时 | 学生的批改结果，供下载后自动删 |
| **识别结果** | 24小时 | 学生的答案数据，涉及隐私 |
| **✅ 标准答案** | **永久** | 教题目，不含学生信息，用于评分 |
| **✅ 题目文件** | **永久** | 教题目本身，供隔年复用 |

## 🔑 关键设计决策（已修正）

| 项目 | 决策 | 原因 |
|------|------|------|
| 标准答案保留 | **永久** | 老师改卷超24小时；隔年要复用 |
| 学生答案卡 | 24小时 | 包含学号等隐私信息 |
| 两种输入方式 | **都支持** | 灵活应对各种场景 |
| 自动对比 | 是 | 系统自动判定答对/错/未作答 |
| 识别后冻结 | 是 | 防止事后改答 |
