# admin-portal 第二期規劃：搬入補習班管理與共用設定

日期：2026-09-29
前置：第一期（選修課管理）已於 2026-09-29 上線，見 `第一期規劃_選修課管理.md`

## 目標

把 tution-portal 裡剩下的行政管理頁全部搬到 admin-portal。搬完後：

- **admin-portal**：所有行政管理（補習班、選修課、共用設定），側邊欄不再有 ↗ 外部連結
- **tution-portal**：只剩補習班老師端（開班申請、我的課程、名冊、排課、點名、統計），拿掉行政側邊欄

## 已確認的決定

1. 「已開課管理」每門課的「名冊／排課／點名」按鈕：**繼續連到 tution-portal 的老師端頁面**，在新分頁開啟
   （頁面只維護一份；管理員第一次點過去可能要在 tution-portal 登入一次）
2. 共用設定（老師管理、申請人密碼重設、教室管理）**這期一起搬**
3. 現有補習班資料是測試資料——與本期無關，本期**不刪除任何資料**；要清理時另外指定範圍、先列清單確認

## 搬移範圍

來源：`tution-portal/src/pages/AdminPanel/AdminPanel.tsx`（以 `/admin/:tab` 切換 8 個分頁）

| 原路徑（tution-portal） | 新路徑（admin-portal） | 內容 | 可進入的身分 |
|---|---|---|---|
| `/admin/approvals` | `/tution/approvals` | 審批管理 | super_admin |
| `/admin/courses` | `/tution/courses` | 已開課管理 | super_admin |
| `/admin/course-report` | `/tution/course-report` | 各課程開課報表 | super_admin、督察員 |
| `/admin/course-attendance` | `/tution/course-attendance` | 各課程出席狀況 | super_admin、督察員 |
| `/admin/usage` | `/tution/usage` | 每日教室使用 | super_admin、教室管理員 |
| `/admin/teachers` | `/settings/teachers` | 老師管理 | super_admin |
| `/admin/password-reset` | `/settings/password-reset` | 申請人密碼重設 | super_admin |
| `/admin/classrooms`、`/classrooms` | `/settings/classrooms` | 教室管理 | super_admin |

身分權限與 tution-portal 現行規則一致（督察員只能看報表與出席、教室管理員只能看每日教室使用）。

### 連帶要搬的檔案

- 頁面：`AdminPanel.tsx`（拆成各分頁一個頁面，不再用一個大檔案切 tab）、`ClassroomManagement.tsx`
- 元件：`components/admin/` 的 ApprovalList、RejectModal、CourseReportTable、CourseAttendanceStatus、
  ClassroomUsageOverview、PasswordResetList，以及出席總表 `AttendanceOverviewTable`
- service：adminService、settingsService、reportService、scheduleService、rosterService
  （後兩個老師端也在用 → admin-portal 各留一份，只保留管理頁用到的函式）
- 工具：semester、validators（日期格式）、scheduleGenerator
- 相依套件：`xlsx`（報表、教室匯出）

## admin-portal 資料夾

```
src/
  shared/      登入、權限、側邊欄（第一期已建）
  optional/    選修課管理（第一期）
  tution/      補習班管理：pages/、components/、services/、utils/，樣式 tu- 前綴
  settings/    共用設定：老師管理、申請人密碼重設、教室管理，樣式 st- 前綴
```

`settings/` 與 `shared/` 分開：shared 是站內基礎設施（登入、版面），settings 是給使用者操作的「共用設定」頁面。

## 多語系

tution-portal 有中英切換（react-i18next），其中「各課程出席狀況」「各課程開課報表」用到翻譯與年級／星期標籤。
admin-portal 只給行政人員使用，**只做中文**：這兩個元件改為直接使用中文標籤（取自 `zh.json`），不引入 i18n。

## admin-portal 權限調整

- 可進入的身分由 `super_admin`、`admin` 擴充為加上 `classroom_manager`
- 每個路由標示可進入的身分；側邊欄只顯示有權限的項目
- 首頁依身分導向：super_admin → 審批管理；督察員 → 選修課總覽；教室管理員 → 每日教室使用

## tution-portal 配合修改

- `/admin`、`/admin/:tab`、`/classrooms` 改為轉址到 admin-portal 對應頁（舊書籤不失效）
- 拿掉行政側邊欄（Sidebar）、`RESTRICTED_ALLOWED_PATHS`／`RESTRICTED_VISIBLE_PATHS`
- 首頁：super_admin／督察員／教室管理員登入後直接轉到 admin-portal；老師不變
- 刪除已搬走的頁面、元件、樣式與只剩管理頁在用的 service（adminService、settingsService、reportService）
- 老師端頁面（`/classes/:id/roster` 等）保留，super_admin 從「已開課管理」點過來時仍可進入

## 不變的部分

- chhsban-tution Worker、所有 API、KV 資料
- 補習班老師端的所有頁面與流程

## 實作結果（2026-09-29）

依上述規劃完成，補充說明：

- **樣式隔離**：搬來的 CSS 以 `admin-portal/scripts/scope-css.py` 加上作用域（補習班 `.tu-scope`、共用設定 `.st-scope`），
  元件程式碼的 class 名稱不用改。原本這些檔案裡有未加前綴的規則（`.btn`、`.modal-*` 等）會互相套用到所有管理頁，
  所以兩種頁面的外框都同時帶 `.tu-scope` 與 `.st-scope`，並依原本順序載入（`tution/styles/index.css`），重現原本外觀
- **翻譯**：`tution/i18n` 是只有中文的替代品，介面與 react-i18next 相容，搬來的元件不用改寫翻譯呼叫；
  已檢查所有用到的翻譯 key 在 zh.json 都查得到
- **AdminPanel 拆頁**：原本 8 個分頁共用的資料（課程、教室、最後上課日期）抽成 `tution/hooks.ts` 的 `useTutionAdminData`
- **每頁可進入的身分**集中在 `shared/access.ts`，路由守衛與側邊欄共用
- **型別**：`TutionSchedule` 原本從 `@chhsban/kv-utils` 引入，管理站改為直接定義（不依賴 kv-utils，CI 不用先建置共用套件）
- **tution-portal 老師端外觀不變**：原本 `classroom-management.css`、`admin-panel.css` 裡有未加前綴的全站規則
  （`.btn`、`.modal-*`、`.form-group`、`.badge` 等）也套用在老師端頁面；刪除管理頁後把這些規則保留在
  `tution-portal/src/styles/legacy-admin-globals.css`，並在 App.tsx 原本 import 管理頁的位置載入，維持樣式順序
- 檢查過老師端用到的 class 沒有只定義在已刪除樣式檔裡的

驗證：admin-portal `tsc --noEmit` 與 build 通過；tution-portal build 通過（`tsc` 只剩既有的 RosterManagement 未使用變數錯誤）。
