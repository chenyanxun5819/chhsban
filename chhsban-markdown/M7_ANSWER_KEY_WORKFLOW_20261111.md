## 问题发现

在 M7（教师端流程）的初始设计中，**缺少了一个关键业务步骤**：

- ❌ 原计划：选择版型 → 下载答案纸 → 学生上传答卷 → 识别结果
- ❌ **缺陷**：识别出学生答案后，无法对比标准答案，因为教师从未输入过正确答案

这会导致系统无法：
1. 判定学生答对/答错/未作答
2. 生成对比分析报告
3. 突出显示需要复核的题目

---

## 解决方案

### 新增工作流步骤

在 M7 中补充**标准答案获取**作为独立阶段，位置在「下载答案纸」之前：

#### ① 新建考试 → 获取标准答案（新增）
教师必须先完成这一步，才能下载答案纸。支持两种方式任选：

**方案 A：扫描标准答案卡（推荐）**
- 教师在空白答案纸上涂出 100 题的正确答案
- 上传该卡的扫描图（JPG/PNG）或 PDF
- 系统使用**同一套识别引擎**解析卡片
- 自动生成 `answerKey` JSON 数组
- 教师可预览并手动调整（如有识别错误）

**方案 B：手动输入答案**
- 逐题选择（A/B/C/D/E 单选框）
- 或粘贴 JSON/CSV 格式
- 实时显示「已填 / 未填」统计

#### ② 下载答案纸 PDF
答案纸配置（证号位数、选项数、版型）自动取自所属组织。

#### ③ 学生上传答卷 → 自动对比
- 上传学生填涂的答案纸
- 识别 + 与标准答案对比
- 生成每题的「答对/答错/未作答」判定

#### ④ 导出结果
- CSV（学号 + 每题答案 + 对错状态）
- 标注图 PDF（错题高亮）

## 技术实现要点

### 数据模型更新

**Firestore `jobs/{jobId}` 文档**

```jsonc
{
  "uid": "...",
  "orgId": "...",
  "templateId": "T100-A4-v1",
  "status": "completed",
  
  // 【新增】标准答案
  "answerKey": ["A","C","B","D","E", ...],  // 长度 = 题数，每项为 A/B/C/D/E
  
  // 识别结果
  "result": {
    "sheets": [
      {
        "studentId": "12345",
        "answers": ["A","C","B",...],
        "correctness": ["correct","correct","correct",...]  // 与标准答案对比
      }
    ]
  },
  
  "pages": 1,
  "createdAt": "2026-11-11T...",
  "expiresAt": "2026-11-12T..."  // 24小时自动删除
}
```

### 关键设计决策

| 决策项 | 选择 | 理由 |
|-------|------|------|
| 两种方式都支持 | 是 | 灵活性最大；方案A利用现有引擎；方案B直接高效 |
| 保存到试卷库 | 否（M7阶段） | 降低M7复杂度；试卷库属第二阶段（14.3节）;保留期24小时无需永久保存 |
| 对比时机 | 上传识别时 | 而非延迟处理；用户立即看到结果 |
| 识别标准答案卡 | 同一套引擎 | 复用现有代码；不必额外开发;准确度有保证 |

### 前端交互流

```
教师登录
  ↓
【新建考试】
  ├─ 版型选择（单选）
  ├─ 考试名、科目（文本输入）
  │
  ├─ 【选标准答案来源】
  │  ├─ [A] 上传标准答案卡图片 
  │  │    ↓ 系统识别
  │  │    ↓ 预览结果 + 手动调整
  │  │
  │  └─ [B] 手动输入答案
  │       ├─ 逐题选择 A-E
  │       └─ 或粘贴 JSON
  │
  ├─ ✓ 确认标准答案
  │
  └─ 【下载答案纸】PDF
         ↓ 教师打印、学生作答
         
  ↓
【上传学生答卷】
  ├─ 选择图片/PDF
  └─ ↓ 自动识别 + 对比标准答案
  
  ↓
【查看结果】
  ├─ 结果表（学号 + 每题 + 对错状态）
  ├─ 标注图预览
  └─ 【导出】CSV + PDF
```

## M7 验收标准补充

新增以下验收项：

| 验收项 | 说明 |
|-------|------|
| **方案 A 准确度** | 上传标准答案卡JPG，系统识别准确率100%（与本地evaluate.py结果一致） |
| **方案 B 导入导出** | 手动输入答案后，导出为JSON格式正确；导入JSON后显示正确 |
| **对比逻辑** | 学生答案与标准答案对比，答对/答错/未作答的判定正确 |
| **数据存储** | answerKey正确存入Firestore jobs/{jobId}，24小时后随整个文档删除 |

## 相关联的设计

### 与 M6（管理系统）的关系
- M6 不涉及标准答案输入，只负责认证、授权、配额
- M7 依赖 M6 的组织/教师设置（学号位数、选项数、开放版型等）

### 与阶段二的衔接
- M7：标准答案**按次使用**，24小时过期
- 阶段二：标准答案**进入试卷库**，可永久保存并隔年复用

### 识别引擎的兼容性
- `omr_core` 对标准答案卡和学生答卷使用**同一套识别流程**
- 结果格式完全相同，便于对比
- 无需额外修改识别核心
