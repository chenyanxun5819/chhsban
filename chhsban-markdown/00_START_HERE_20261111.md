### 新增工作流阶段（M7）

```
原版（缺陷）：选版型 → 下载答案纸 → 上传学卷 → 识别（无法分析）

新版（完整）：
├─ 选择版型 + 考试信息
├─ 【新增】获取标准答案
│  ├─ 方案A：扫描答案卡
│  └─ 方案B：手动输入
├─ 下载答案纸
├─ 学生作答
├─ 上传学卷 + 自动识别
├─ 与标准答案自动对比
├─ 查看答对/答错/未作答结果
└─ 导出 CSV + 标注图
```

## ✨ 设计亮点

### 1. 两种方案的灵活性
- **方案A**：利用现有识别引擎，无需新开发，准确度有保证
- **方案B**：支持多种输入格式（单题、JSON、CSV），覆盖各种场景
- **都支持**：最大化用户选择，适应不同工作流

- 标准答案存入 `jobs/{jobId}.answerKey`
- 与学生资料同周期：24 小时后自动删除
- 符合隐私保护原则，不占用存储成本
