# M7 标准答案工作流 — 快速参考卡

---

## 🚨 问题

**原设计缺陷**：
- 教师下载答案纸后，学生上传答卷被识别出来
- ❌ **但无法对比标准答案**，因为教师从没输入过
- ❌ 无法判定答对/答错
- ❌ 系统功能不完整

---

## 💡 解决方案

**补充一个步骤**：在下载答案纸之前，先输入标准答案。

```
新增步骤
     ↓
【新建考试】
  ├─ 版型 + 考试名/科目
  └─ 【输入标准答案】← 这是新的
      ├─ 方案A：上传扫描卡
      └─ 方案B：手动输入
      
  → 下载答案纸
  → 学生作答与上传
  → 系统自动对比
  → 查看答对/答错/未作答
  → 导出结果
```

---

## 📝 两种方案

### 方案 A：扫描标准答案卡 ⭐ 推荐

```
涂写标准答案卡
  ↓
扫描成图片（JPG/PNG/PDF）
  ↓
上传到系统
  ↓
系统自动识别
  ↓
预览结果 + 可手动调整
  ↓
确认保存
```

**优点**:
- 利用现有识别引擎（无需开发）
- 准确度高（同一套算法）
- 防止手动输入错误
- 教师工作流自然

---

### 方案 B：手动输入答案

```
打开答案输入界面
  ↓
逐题选 A/B/C/D/E
或粘贴 JSON/CSV
  ↓
实时显示填写进度
  ↓
支持导入/导出
  ↓
确认保存
```

**优点**:
- 直接快速
- 无需扫描
- 支持批量粘贴
- 实时反馈

## 🔑 关键决策

| 决策 | 说明 |
|------|------|
| **两种方案都要** | 灵活性最大，适应各种场景 |
| **不进试卷库** | M7 只处理 24 小时内的数据；试卷库是第二阶段功能 |
| **24小时后删除** | 与学生资料同周期，符合隐私保护原则 |
| **识别后冻结** | 防止教师事后改答 |
| **不计配额** | 这是"准备工作"，只有学生答卷计费 |

## ❓ 常见问题

**Q: 这会延迟 M7 完成吗？**  
A: 是的，但这是必要的功能。不做就无法验收。

**Q: 标准答案为什么要 24 小时删除？**  
A: 遵循"学生资料保护"原则。试卷库（永久保存）在第二阶段。

**Q: 能先做只有一种方式吗？**  
A: 可以，但两种都做的价值是灵活性和覆盖率。

**Q: 需要特殊的 E2 实验吗？**  
A: 是的。需要用实际复印机扫描标准答案卡来验证识别准确度。
