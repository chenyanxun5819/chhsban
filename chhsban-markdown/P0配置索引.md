## ⚡ 常用命令

```bash
# 在根目錄執行

# 驗證配置
node scripts/verify-config.js

# 安裝所有項目依賴
npm install

# 部署公文系統
cd chhsban-acadoc && wrangler deploy

# 部署補習班系統
cd chhsban-tution && npm install && wrangler deploy

# 檢查 Cloudflare secrets
cd chhsban-acadoc && wrangler secret list

# 查詢 KV 數據
wrangler kv:key list --namespace-id=9d870e2344c84c74a1ed2f2851c93408
```

## 📝 新增 KV 的標準流程

參考：[KV_MANAGEMENT_QUICK_GUIDE.md](../KV_MANAGEMENT_QUICK_GUIDE.md)

1. 在 Cloudflare 中建立 KV → 記下 namespace ID
2. 更新 `packages/cloudflare-config/src/kv-namespace.ts`
3. 更新 `packages/cloudflare-config/src/workers.ts`（如需要）
4. 執行 `wrangler deploy`
