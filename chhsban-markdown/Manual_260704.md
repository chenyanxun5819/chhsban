## 📝 **第二個問題回答：日後增加新 KV 的標準流程**

### **三步法（簡單易用）**

#### **步驟 1️⃣：在 Cloudflare 建立 KV**
```bash
cd chhsban-acadoc
wrangler kv:namespace create "my_kv"
# 記下 namespace ID
```

#### **步驟 2️⃣：更新 cloudflare-config**
編輯 `packages/cloudflare-config/src/kv-namespace.ts`：
```typescript
FORM_KV: {
  binding: "FORM_KV",
  id: "新_namespace_id",
  description: "說明"
}
```

#### **步驟 3️⃣：更新 Worker 綁定**
編輯 `packages/cloudflare-config/src/workers.ts`，將 `"FORM_KV"` 加入相應 Worker 的 `kvNamespaces` 陣列。

#### **完成！** 部署時自動套用：
```bash
wrangler deploy
```
