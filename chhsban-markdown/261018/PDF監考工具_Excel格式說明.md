# PDF監考名單標記工具 - Excel 格式說明

## Excel 導入格式

### 工作簿結構
需要包含 **2 個工作表**：

#### 1️⃣ 老師名單工作表
包含老師資料的工作表。系統會自動尋找包含以下欄位的工作表。

| 欄位名稱 | 別名 | 說明 | 示例 |
|---------|------|------|------|
| **代號** | Initial / INITIAL / 代号 | 老師的代號（縮寫） | `A01`, `長`, `贤` |
| **教師姓名** | Name / 教师姓名 / 教師姓名 / 姓名 | 老師的完整姓名 | `張老師`, `李明` |
| **座號** | Seat / Seat No / Seat Number / 座位号 / 座位號 | 老師的座位號碼 | `1`, `27`, `38` |
| **教職員編號** | Teacher ID / ID / 教职员编号 / 教職員編號 | 教職員工號 | `T001`, `T119` |
| **組別** | Group / 组别 / 組別 | 部門或科目分組 | `語文`, `華文 Chinese` |

**注意：** 
- 系統會自動識別上述別名中的任何一個，不區分大小寫
- 必須至少包含 **代號** 和 **教師姓名** 兩個欄位

#### 2️⃣ 座位區塊工作表
包含座位區塊分類的工作表。

| 欄位名稱 | 別名 | 說明 | 示例 |
|---------|------|------|------|
| **座位號** | Seat / Seat No / Seat Number / 座位号 / 座位號 | 座位號碼 | `1`, `2`, `3` |
| **區塊** | Block / 區塊 / 区块 | 座位所在的區塊 (通常為 L/R/C) | `L`, `R`, `C` |

**說明：**
- L = 左區 (Left)
- R = 右區 (Right)  
- C = 中間區 (Center)

### 完整範例

#### 工作表 1: 老師名單
```
代號    教師姓名    座號    教職員編號    組別
A01     張老師      1       T001         語文
A02     李老師      2       T002         數學
A03     王老師      3       T003         英文
```

#### 工作表 2: 座位區塊
```
座位號   區塊
1       L
2       L
3       R
4       R
5       C
```

## 新增功能 - 下載模板

✅ **功能已新增**

在 GUI 的「設定」區域中，現在有一個 **「下載老師名單模板」** 按鈕：

1. 點擊按鈕
2. 選擇保存位置
3. 自動生成包含範例資料的 Excel 模板
4. 模板包含：
   - 格式正確的欄位名稱
   - 示例資料 (3 位老師, 5 個座位)
   - 藍色表頭，便於識別
   - 適當的列寬設定

## 使用流程

### 首次使用
1. 開啟程式
2. 點擊 **「下載老師名單模板」**
3. 保存模板檔案
4. 用 Excel 開啟，根據需要編輯資料
5. 點擊 **「匯入老師名單 Excel」** 導入自己的設定

### 後續使用
- 直接使用自己建立的 Excel 檔案導入
- 或下載新的模板重新建立
