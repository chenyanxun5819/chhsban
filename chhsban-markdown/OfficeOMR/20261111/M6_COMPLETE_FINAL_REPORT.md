## 🔧 技术实现细节

### Firestore 集合集成

| 集合名 | 操作 | 字段 |
|--------|------|------|
| `orgs` | CRUD | name, code, id_digits, id_prefix, option_count, template_list, active |
| `allowedUsers` | CRUD | email, role, orgId, active, daily_quota_override, createdAt, updatedAt |
| `settings` | Read/Write | defaultDailySheetsPerUser, studentDataRetentionHours, maxPagesPerUpload 等 6 个参数 |
| `usage` | Read | 用于查询 usage/{uid}_{yyyymmdd} 格式的文档 |

### API 调用与异步处理

所有 Firestore 操作使用正确的 API：
- ✅ `.doc()` 而非 `.document()`（已全部修复）
- ✅ `.add()` 用于新增文档（自动生成 ID）
- ✅ `.update()` 用于修改（部分字段）
- ✅ `.delete()` 用于删除
- ✅ 事务与错误处理（try-catch）

### 前端验证

所有表单都有前端验证：
- 邮箱格式：正则表达式检查
- 组织代号：3-10字符，仅字母数字
- 学号位数：3-12 范围
- 数字参数：正整数验证

## 📞 支持与问题反馈

如果在使用中遇到问题，请检查：

1. **浏览器控制台** (F12 → Console)：是否有 JavaScript 错误
2. **Firebase 控制台** (Firestore)：是否能查看 orgs/allowedUsers/settings 的数据
3. **网络请求** (F12 → Network)：是否有 HTTP 错误（如 403 权限问题）

常见问题：
- ❓ 修改后没有效果？→ Ctrl+Shift+R 强制刷新
- ❓ 新增组织后看不到？→ 刷新页面或检查 Firestore Rules
- ❓ 系统设置保存失败？→ 检查控制台错误信息
