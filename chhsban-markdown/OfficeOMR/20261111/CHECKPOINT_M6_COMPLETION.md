## 🔍 技术重点

### 学到的最重要的东西

**1. Firestore API 容易混淆**
- `.document()` 和 `.doc()` 在运行时才报错
- 必须全代码库搜索，而不是只改一处
- IDE 代码补全很关键

**2. 部署验证不可省**
- 不能假设 CI/CD 会成功
- 必须手动执行 firebase deploy 并检查输出
- 输出会告诉你是否真的上传了新文件

**3. 模态框复用节省代码**
- 从 5 个不同的模态框 → 1 个 `showModal()` 通用方法
- 代码更清晰，用户体验更一致
- 减少维护负担

### 核心架构决策

**学号灵活配置**
```javascript
// 管理员可以为每个学校配置不同规则
org.id_digits = 8        // 位数
org.id_prefix = ""       // 前缀
org.option_count = 5     // 选项数
org.template_list = ["T100", "T060"]  // 版型
```

**分级配额系统**
```javascript
// 全局默认 + 个别覆盖
settings.defaultDailySheetsPerUser = 30
teacher.daily_quota_override = 50  // 可选
```

**实时参数读取**
```javascript
// 后端 Cloud Functions 动态读取参数
settings = db.collection('settings').doc('global').get()
// 无需重新部署即可生效
```
