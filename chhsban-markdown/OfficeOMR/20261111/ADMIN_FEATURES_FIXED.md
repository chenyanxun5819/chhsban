## 🔧 具体修复内容

### 1️⃣ 系统设置错误修复

**问题**: 第三个选项卡显示 `❌ 加载失败: this.firestore.collection(...).document is not a function`

**根因**: Firestore SDK Web 版本中，获取单个文档应该用 `.doc()` 而非 `.document()`

**修复**:
```javascript
// ❌ 错误的写法
const settingsRef = this.firestore.collection('settings').document('global');

// ✅ 正确的写法
const settingsRef = this.firestore.collection('settings').doc('global');
```

**文件**: `OfficeOMR/web/js/pages/admin.js` 第 219 行

### 2️⃣ 新增教师功能实现

#### UI 增强
- 在教师管理页面顶部添加了 `+ 新增教师` 按钮
- 按钮风格与系统统一（蓝色主题色）
- 按钮位置：标题右侧对齐

#### 模态框表单
打开时会显示一个表单，包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 邮箱 | 文本（Email） | ✅ | 教师账户邮箱 |
| 所属组织 | 下拉选择 | ✅ | 自动加载现有组织 |
| 状态 | 下拉选择 | ❌ | 活跃 / 停用（默认活跃） |

#### 功能流程
```
点击"+ 新增教师"
    ↓
打开模态框表单
    ↓
从 Firestore orgs 集合加载组织列表
    ↓
用户填写邮箱和选择组织
    ↓
点击"添加"按钮
    ↓
保存到 allowedUsers 集合 (role: 'teacher')
    ↓
自动关闭模态框
    ↓
自动刷新教师列表显示新添加的教师
```

#### 代码位置
- **主要逻辑**: `OfficeOMR/web/js/pages/admin.js`
  - `showAddTeacherModal()` 方法：显示模态框
  - `handleAddTeacher()` 方法：处理表单提交
  - `loadOrgsToSelect()` 方法：加载组织列表到下拉框

## 📝 技术细节

### Firestore 数据结构

#### allowedUsers 集合
```javascript
{
  email: "teacher@example.com",      // 教师邮箱
  role: "teacher",                   // 角色标识
  orgId: "chhs",                     // 所属组织代码
  active: true,                      // 是否活跃
  createdAt: Timestamp,              // 创建时间
  updatedAt: Timestamp               // 更新时间
}
```

#### settings/global 文档
```javascript
{
  // 这是全局配置文档，用于存储系统级别参数
```
