## 批量部署腳本

### PowerShell 一鍵部署所有項目

```powershell
# 保存為 deploy-all.ps1

$projects = @(
    @{ name = "tution-portal"; cmd = "npm run build && wrangler pages deploy dist --project-name=tution-portal" },
    @{ name = "chhsban-portal"; cmd = "npm run build && wrangler pages deploy dist --project-name=chhsban-portal" },
    @{ name = "teacher-management-portal"; cmd = "npm run build && wrangler pages deploy dist --project-name=teacher-management-portal" }
)

$baseDir = "d:\chhsban"

foreach ($project in $projects) {
    $projectPath = Join-Path $baseDir $project.name
    
    Write-Host "📦 正在部署: $($project.name)" -ForegroundColor Cyan
    
    if (Test-Path $projectPath) {
        Push-Location $projectPath
        Invoke-Expression $project.cmd
        if ($LASTEXITCODE -eq 0) {
            Write-Host "✅ $($project.name) 部署成功" -ForegroundColor Green
        } else {
            Write-Host "❌ $($project.name) 部署失敗" -ForegroundColor Red
        }
        Pop-Location
        Write-Host ""
    } else {
        Write-Host "❌ 找不到項目路徑: $projectPath" -ForegroundColor Red
    }
}

Write-Host "🎉 部署流程完成" -ForegroundColor Green
```

**使用方法**:
```powershell
# 在 PowerShell 中執行
.\deploy-all.ps1
```

### 部署前檢查

- [ ] 所有代碼已提交到 Git

## 常見問題

### Q1: 部署時出現 "Unauthorized" 錯誤

**原因**: Wrangler 未登錄或登錄過期  
**解決方案**:
```powershell
wrangler logout
wrangler login
```

---

### Q2: 部署失敗 - "dist 目錄不存在"

**原因**: 沒有執行 `npm run build`  
**解決方案**:
```powershell
npm install  # 確保依賴完整
npm run build  # 執行構建
```

---

### Q3: TypeScript 編譯錯誤

**原因**: 代碼有型別檢查錯誤  
**解決方案**:
```powershell
# 檢查錯誤
npm run build

# 查看詳細錯誤信息
npx tsc --noEmit

# 修復錯誤後重試
```

---

### Q4: 環境變量不生效

**原因**: 
- 環境變量未在 `wrangler.toml` 中配置
- 環境變量名稱不符合預期

**解決方案**:
1. 檢查 `wrangler.toml` 中的環境變量配置
2. 確保在代碼中正確引用 (如 `process.env.VITE_API_URL`)
3. 重新部署

---

### Q5: 如何回滾到上一個版本？

**方案 1: Git 回退**
```powershell
# 查看提交歷史
git log --oneline

# 回退到特定版本
git revert <commit-hash>
git push

# 重新部署
npm run build && wrangler pages deploy dist --project-name=<project-name>
```

**方案 2: Cloudflare 控制台直接回滾**
- 訪問 https://dash.cloudflare.com/
- 選擇 Pages 項目
- 在部署歷史中選擇回滾

## 高級部署配置

### 自動部署 (GitHub Actions)

在 `.github/workflows/deploy.yml` 配置 CI/CD:

```yaml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: 18
      
      - name: 安裝依賴
        run: npm ci
      
      - name: 構建
        run: npm run build
      
      - name: 部署到 Cloudflare Pages
        env:
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
        run: npx wrangler pages deploy dist --project-name=tution-portal
```
