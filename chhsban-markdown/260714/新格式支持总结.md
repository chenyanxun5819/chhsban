## 核心改动

### 问题
系统之前只支持旧格式：
- 每个 Excel sheet = 一个项目
- 一个 sheet 内只能有一个项目代码（B2）
- 同一学生的多项奖励必须合并在一个单元格

新格式需要支持：
- 一个表格可包含多个项目代码（按 J 栏分组）
- 每行代表一条奖项记录（而非一个学生）
- 同一学生的多个奖项分行存储，需要合并回单一备注

### 实现方案

#### 1. 两层解析架构
- **格式识别** (`detect_sheet_format`): 区分旧格式（B1/B2）vs 新格式（I/J/K 合并格）
- **旧格式** (`parse_old_sheet`): 兼容现有 sheet = 一个项目的逻辑
- **新格式** (`parse_new_sheet`): 按 J 栏项目代码聚合，同学生多奖项合并

#### 2. UI 改动
**旧方案**:
```
选择文件 → 自动列出所有项目 → 下拉选单选一个 → 上传
```

**新方案**:
```
选择文件 → 输入表格名称 → 按"载入表格"显示预览 → 自动拆成多项目 → 逐项上传
```

- 移除自动的项目下拉单
- 改为手动输入表格名称（例如 `2026年上传汇整`）
- 预览表新增"项目代码"、"比赛日期"两列
- 批量上传时显示各项目的进度与结果摘要

#### 3. 上传线程改动
- 从单项目上传改为多项目批量上传
- 按项目逐次调用 `upload_student_scores()`
- 累计各项目成功/失败数
- 最终汇总显示（项目数、学生记录、各项目摘要）

## 文件改动

### 修改文件
**`d:\chhsban\sms_app\ui\pages\score_upload_page.py`**

#### 新增函数
- `normalize_text(value)`: 统一文字格式（去除非break space 等）
- `normalize_student_id(value)`: 统一学号格式（22007.0 → "22007"）
- `normalize_date_value(value)`: 统一日期格式（多种输入 → YYYY-MM-DD）
- `detect_sheet_format(ws)`: 识别工作表格式（旧/新/未知）
- `parse_old_sheet(ws)`: 解析旧格式工作表
- `parse_new_sheet(ws)`: 解析新格式工作表，按 J 栏分组与多奖项合并
- `inspect_upload_sheet(ws)`: 统一入口，自动选择解析器

#### 改动类与方法
- `UploadThread.__init__`: 参数从 `sheet_name` 改为 `table_name`
- `UploadThread.run()`: 支持多项目批量上传，逐项上传与汇总
- `ScoreUploadPage._create_ui()`: 移除项目下拉单，改为表格名称输入框 + 载入按钮
- `ScoreUploadPage.select_file()`: 文件选后可自动列表格名称
- `ScoreUploadPage.load_table()`: 新增，载入指定表格并显示预览
- `ScoreUploadPage._load_preview()`: 改为接收统一解析结果显示预览
- `ScoreUploadPage.start_upload()`: 改为读取表格名称输入
- `ScoreUploadPage.refresh_projects()`: 刷新后自动重新载入表格

#### 移除代码
- 移除了 `ProjectCacheManager` 引入与旧的项目过滤逻辑

## 使用流程

### 上传新格式 XLSX
1. 打开 `SMS成绩上传工具 V2.4.exe`
2. 点击【成绩上传】选项卡
3. 点击【📂 选择 Excel 文件】，选择 `2026学生学术登记_claude公式_SMS上傳.xlsx`
4. 在"表格名称"输入框输入表格名称（如 `2026年上传汇整`），按 Enter 或点击【📋 载入表格】
5. 预览中应显示 4 个项目、合并的多奖项记录
6. 点击【📤 开始上传】
7. 系统自动逐项上传，每个项目进度独立显示

### 仍支持旧格式 XLSX
- 流程完全相同，系统自动识别格式
- 旧格式的下拉单式操作将被表格名称输入代替
