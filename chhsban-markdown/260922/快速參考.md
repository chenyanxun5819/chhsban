# ⚡ 快速參考卡 - Google Sheet 權限設定

## 🎯 一分鐘快速開始

| 步驟 | 操作 |
|-----|------|
| 1️⃣ | 打開 Sheet → **工具** → **指令碼編輯器** |
| 2️⃣ | 複製 `SetSheetPermissions_Advanced.gs` 全部代碼 |
| 3️⃣ | 貼到 Apps Script 編輯器 |
| 4️⃣ | 選擇 `executePermissionSetup` → 點擊 ▶️ **執行** |
| 5️⃣ | 授權 → 完成！ |
