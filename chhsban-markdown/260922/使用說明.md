# Google Sheet 批量權限設定 - 使用說明

## 📋 目標
為 `ecchhs110@chhsban.edu.my` 帳號設定：
1. **全域編輯權限** - 整個試算表
2. **範圍編輯權限** - A:F、38:975、1:6 三個範圍

---

## 🚀 使用步驟

### 第一步：開啟 Apps Script
1. 打開你的 Google Sheet: https://docs.google.com/spreadsheets/d/1qiO66ja_NAEk0axmZ3hdRMoHY7eD9QofzNfPdeHln04/
2. 點選 **工具 (Tools)** → **指令碼編輯器 (Script Editor)**
3. 或直接訪問：https://script.google.com/

### 第二步：貼上代碼
1. 在 Apps Script 編輯器中，清空預設代碼
2. 複製下方「**SetSheetPermissions_Advanced.gs**」 中的所有代碼
3. 全部貼到編輯器中

### 第三步：執行代碼
1. 選擇函數下拉菜單，選擇 **`executePermissionSetup`**
2. 點擊 ▶️ **執行 (Run)** 按鈕
3. 首次執行會要求授權：
   - 點擊 **Review Permissions**
   - 選擇你的 Google 帳號
   - 按「允許」授予權限

### 第四步：查看執行結果
- 點擊 **執行日誌 (Execution log)** 查看運行結果
- 應該會看到 ✅ 符號表示各項設定成功

---

## 📝 功能說明

### 主要函數
| 函數名 | 用途 |
|--------|------|
| `executePermissionSetup()` | ⭐ 主執行函數，執行所有權限設定 |
| `verifyPermissions()` | 驗證權限設定是否成功 |
| `revokeAllPermissions()` | ⚠️ 移除所有已設定的權限（用於復原） |
| `removeAllProtections()` | ⚠️ 移除所有範圍保護（用於復原） |

### 權限層次
```
1️⃣ 檔案級別（全局）
   └─ ecchhs110@chhsban.edu.my 獲得整個試算表的編輯權限

2️⃣ 範圍級別（特定區域）
   ├─ 欄 A:F (所有行)
   ├─ 行 38:975 (所有列)
   └─ 行 1:6 (所有列)
   
   每個範圍都會被保護，只有：
   ✅ 檔案所有者
   ✅ ecchhs110@chhsban.edu.my
   能夠編輯
```

## ⚙️ 進階設置

### 修改目標帳號
如需改為其他帳號，編輯代碼頂部：
```javascript
const TARGET_EMAIL = "new.email@example.com";
```

### 修改保護範圍
編輯 `setupProtectedRanges` 函數中的 `rangesToProtect` 陣列：
```javascript
const rangesToProtect = [
  { a1Notation: "A:F", description: "欄 A 到 F" },
  { a1Notation: "38:975", description: "行 38 到 975" },
  { a1Notation: "1:6", description: "行 1 到 6" },
  // 添加更多範圍...
];
```

## ❌ 常見問題

### Q1: 執行時出現 "Permission denied" 錯誤
**A**: 
- 確認你是該 Google Sheet 的所有者或編輯者
- 清除瀏覽器緩存並重新登錄
- 確保授予 Apps Script 必要的權限

### Q2: 我想復原已設定的權限
**A**: 執行以下函數：
1. 點擊函數下拉菜單，選擇 **`revokeAllPermissions()`**
2. 點擊執行

### Q3: 如何驗證權限是否設定成功？
**A**: 執行 **`verifyPermissions()`** 函數查看詳細報告

### Q4: 可以只針對某些工作表設定嗎？
**A**: 修改 `setupRangePermissionsForAllSheets` 函數，使用 `sheet.getByName()` 只處理特定工作表

## 🔐 安全性說明

- ✅ 此代碼僅添加編輯權限，**不會刪除或修改任何資料**
- ✅ 只有檔案所有者能執行此腳本
- ✅ 每項操作都會記錄在執行日誌中
- ✅ 可隨時執行 `revokeAllPermissions()` 復原
